# Клиент Galaxy

## Запуск

Установите зависимости и запустите клиент из этой папки: `npm install`, затем `npm run dev`. API по умолчанию ожидается на `http://localhost:3005`; другой адрес можно задать переменной Vite `VITE_API_URL`.

Войдите по email или зарегистрируйтесь: при регистрации нужно дважды ввести одинаковый пароль. Затем откройте ангар и выйдите в космос. На сцене WASD или стрелки перемещают корабль; переключатель зон подключает к глобальной карте или локальному инстансу. Для полноценной игры клиенту нужны запущенный сервер, схема PostgreSQL и действительный токен.
