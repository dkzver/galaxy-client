# Клиент Galaxy

React + Vite: экран входа, ангар-магазин и космическая сцена.

## Запуск

```
npm install
npm run dev
```

API по умолчанию ожидается на `http://localhost:3005`; другой адрес задаётся переменной
`VITE_API_URL`. Нужен запущенный сервер из `../server`.

## Каталог

`src/data/catalog.json` — **генерируемый** файл: проекция корневого `../galaxy-admin-data.json`
без `stellarSystems`. Править его вручную нельзя, источник один — корневой каталог.
Сборка проекции выполняется автоматически перед `dev` и `build`, вручную — `npm run sync:catalog`.

## Ангар

Четыре колонки: корабль игрока, список товаров, содержимое корабля, консоль выбранного объекта.

- Клик по креплению оставляет в списке совместимое оборудование, клик по занятому креплению
  или трюму — выбирает предмет.
- Клик по контейнеру переключает список на ресурсы, которые он принимает (`prop2`), и показывает
  остаток вместимости.
- Покупка оборудования сама выбирает первый подходящий слот, затем трюм; если места нет —
  кнопка заблокирована, причина написана над ней.
- Ресурс покупается и продаётся по 1 кг; контейнер с грузом продаётся только вместе с грузом.
- В режиме «корабли к продаже» третья колонка скрывается, справа показывается карточка модели.

Причина отказа всегда пишется над кнопкой; модальные окна используются только для подтверждения
продажи корабля и контейнера с грузом. `Esc` закрывает диалог или вылетает на карту.

## Космос

WASD или стрелки перемещают корабль, переключатель зон подключает к глобальной карте или
локальному инстансу. Для полноценной игры нужны запущенный сервер, схема PostgreSQL и токен.
